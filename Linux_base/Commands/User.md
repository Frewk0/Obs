
### 1. `useradd` — Створення нових користувачів

Ця команда звертається до ядра системи та конфігураційних файлів (`/etc/passwd`, `/etc/shadow`, `/etc/group`), щоб зареєструвати нового користувача.

**Базовий синтаксис:**

Bash

```
sudo useradd [прапорці] ім_я_користувача
```

**Ключові прапорці (Опції):**

- **`-m` (або `--create-home`)**: Абсолютно критичний прапорець. За замовчуванням у багатьох дистрибутивах Linux `useradd` _не створює_ домашню папку. Цей прапорець змушує систему автоматично створити каталог (зазвичай у `/home/ім_я`) і скопіювати туди базові конфігураційні файли (наприклад, `.bashrc`) з шаблону `/etc/skel`.
    
- **`-d /шлях/до/папки`**: Використовується, якщо ти хочеш, щоб домашня папка знаходилася не в стандартному `/home/ім_я`, а в іншому місці.
    
- **`-s /шлях/до/оболонки`**: Задає командну оболонку (shell) за замовчуванням. Наприклад, `-s /bin/bash` або `-s /bin/sh`.
    
- **`-g назва_групи`**: Задає **основну** (первинну) групу користувача.
    
- **`-G група1,група2`**: Додає користувача до **додаткових** (вторинних) груп. Назви груп пишуться через кому без пробілів.
    
- **`-u UID`**: Дозволяє вручну задати числовий ідентифікатор користувача (User ID). Зазвичай система сама видає перший вільний номер, починаючи з 1000.
    

**Приклад із життя:**

Bash

```
sudo useradd -m -s /bin/bash -d /home/student ivan
```

_Створює користувача `ivan`, генерує йому домашню папку `/home/student` та встановлює оболонку `bash`._

### 2. `usermod` — Зміна параметрів існуючого користувача

Якщо `useradd` створює, то `usermod` (User Modify) — редагує. 

**Базовий синтаксис:**

Bash

```
sudo usermod [прапорці] ім_я_користувача
```

**Ключові прапорці (Опції):**

- **`-c "Коментар"` (GECOS field)**: Додає або змінює додаткову інформацію про користувача (повне ім'я, прізвище, номер телефону). 
    
- **`-d /новий/шлях -m`**: Змінює шлях до домашньої папки. Прапорець **`-m`** (move) тут обов'язковий — він фізично переносить усі існуючі файли зі старої папки в нову.
    
- **`-l нове_ім_я` (login)**: Змінює логін користувача.
    
- **`-aG група` (append Group)**: Додає користувача до нової групи. **Увага:** завжди використовуй `-a` разом із `-G`! Якщо написати просто `-G група`, система видалить користувача з усіх інших додаткових груп і залишить тільки в цій.
    
- **`-s /bin/sh`**: Змінює командну оболонку.
    
- **`-e YYYY-MM-DD` (expire)**: Встановлює дату, коли обліковий запис буде автоматично заблоковано.
    
- **`-u новий_UID`**: Змінює числовий ідентифікатор користувача.
    

**Приклад із життя:**

Bash

```
sudo usermod -c "Dmitro Kostenko" -d /home/kostenko -m ivan
```

_Додає прізвище та ім'я, а також переносить домашню папку користувача `ivan` у `/home/kostenko`._

### 3. `passwd` — Управління паролями

Сам по собі створений користувач не може увійти в систему, поки йому не зададуть пароль (його обліковий запис вважається заблокованим).

**Базовий синтаксис:**

Bash

```
sudo passwd ім_я_користувача
```

Після введення команди система попросить двічі ввести новий пароль (символи на екрані при цьому не відображатимуться — це стандарт безпеки Linux).

**Додаткові прапорці:**

- **`-l` (lock)**: Блокує пароль користувача (додає символ `!` в хеш пароля у файлі `/etc/shadow`), унеможливлюючи вхід.
    
- **`-u` (unlock)**: Розблоковує пароль.
    
- **`-e` (expire)**: Робить поточний пароль недійсним. Користувач буде змушений придумати новий пароль при наступному вході в систему.

### 4. `userdel` — Видалення користувачів

Команда для знищення облікових записів.

**Базовий синтаксис:**

Bash

```
sudo userdel [прапорці] ім_я_користувача
```

**Ключові прапорці:**

- **`-r` (remove)**: Найважливіший прапорець. Якщо виконати команду без нього, система просто видалить логін, але домашня папка та всі файли користувача залишаться на диску як "сироти". Прапорець `-r` видаляє логін, домашню папку та поштову скриньку користувача.

### 5. `groupadd` — Створення нових груп

Для об'єднання користувачів та спрощення управління правами.

**Базовий синтаксис:**

Bash

```
sudo groupadd [прапорці] назва_групи
```

- **`-g GID`**: Дозволяє вручну вказати числовий ідентифікатор групи (Group ID).

### 6. Перемикання між сесіями (`su` / `sudo`)

Щоб працювати від імені іншого користувача або адміністратора (root).

- **`su ім_я_користувача` (Switch User)**: Перемикає на іншого користувача, але залишає змінні середовища (наприклад, поточну директорію) від попереднього користувача.
    
- **`su - ім_я_користувача`**: Правильний спосіб перемикання. Дефіс `-` імітує повноцінний логін — система завантажує змінні середовища нового користувача і перекидає тебе в його домашню папку.
    
- **`su -`** або **`sudo su -`**: Перемикання на права абсолютного адміністратора (root).

### 7. Управління власниками (`chown` та `chgrp`)

У Linux кожен файл і папка належать конкретному **Власнику** (User) та конкретній **Групі** (Group).

- **`chown` (Change Owner)**: Змінює власника файлу/папки.
    
    - Синтаксис: `sudo chown новий_власник назва_файлу`
        
    - Можна змінити відразу і власника, і групу: `sudo chown власник:група назва_файлу`
        
    - **Прапорець `-R` (Recursive)**: Застосовує зміни до папки та всіх файлів, які знаходяться всередині неї.
        
- **`chgrp` (Change Group)**: Змінює лише групу, до якої належить файл.
    
    - Синтаксис: `sudo chgrp нова_група назва_файлу`

### 8. `chmod` — Зміна прав доступу (Change Mode)

Найскладніша, але найважливіша тема. Права визначають, хто може читати (Read), писати (Write) та виконувати (Execute) файли.

Права діляться на 3 категорії (саме в такому порядку):

1. **u (User)** — Власник файлу.
    
2. **g (Group)** — Група, якій належить файл.
    
3. **o (Others)** — Всі інші (решта світу).
    

Є два способи задавати права: символьний та числовий.

#### Спосіб А: Символьний (Літерний)

Дуже інтуїтивний спосіб. Використовує знаки `+` (додати права), `-` (забрати права), `=` (встановити точно такі права, скинувши інші).

- **`r`** (read) — право читати вміст / переглядати список файлів у папці.
    
- **`w`** (write) — право змінювати вміст / створювати файли в папці.
    
- **`x`** (execute) — право запускати скрипти / заходити всередину папки.
    

**Приклади:**

- `chmod g+w test.txt` — Дозволити групі (g) записувати (+w) у файл.
    
- `chmod o-rx test.txt` — Заборонити всім іншим (o) читати (-r) і виконувати (-x) файл.
    
- `chmod u=rwx,g=rw,o= test.txt` — Власнику дати всі права, групі читання і запис, іншим — забрати всі права.
    

### Які права ми даємо? (Дії)

Існує лише три базових права (RWX). Але їхнє значення **кардинально відрізняється** для файлів і для папок (директорій). Це улюблене питання на співбесідах!

|**Право**|**Символ**|**Цифра**|**Що означає для ФАЙЛУ**|**Що означає для ПАПКИ**|
|---|---|---|---|---|
|**Read**|`r`|**4**|Читати вміст файлу (`cat`, `less`)|Бачити список файлів у папці (`ls`)|
|**Write**|`w`|**2**|Редагувати вміст файлу (`nano`, `>`)|Створювати, видаляти та перейменовувати файли в ній|
|**Execute**|`x`|**1**|Запускати файл як програму/скрипт (`./script.sh`)|**Заходити всередину папки (`cd`)**|
